# tmp-calgap-task

Participant-facing pages for a research study on how people use an AI
assistant when reading corporate financial disclosures. **Temporary test
deployment.**

- `/`   — English interface
- `/ko/` — Korean interface

The study material is the same in both: the excerpts, the questions, the
assistant's answers and its confidence statements stay in the original English,
because they are the stimulus. Only the interface is translated.

This repository is public only because GitHub Pages requires it. It holds
generated files. It is not the project: the design, the analysis, the stimulus
construction and the answer key live in a private repository, and nothing here
records which assistant answers are correct.

Generated by `tools/build_task_site.py`. Do not edit by hand.
