# tmp-calgap-task

Participant-facing page for a research study on how people use an AI assistant
when reading corporate financial disclosures. **Temporary test deployment.**

This repository is public only because GitHub Pages requires it. It holds one
generated file. It is not the project: the design, the analysis, the stimulus
construction and the answer key live in a private repository, and nothing here
records which assistant answers are correct.

Generated by `tools/build_task_site.py`. Do not edit `index.html` by hand.
